Your path

Every step carries its stage, in the words of the Estate page: built, in construction, specification, designed, named.

The analyst and the designer

You write the specification as sentences, and what you hand over is a prototype that runs and a deployment that has been rehearsed.

  1. State the specification in natural language that runs. built · see: Natural, and executable
  2. Express workflows, rules and constraints as rules over graphs. built · see: Diagramming & graphs
  3. Declare the interface under the law of the interface, composed in a face file. in construction · see: Zui constitution
  4. Define, emulate and deploy: the whole solution runs on a twin before it runs anywhere real. built · see: Emulating the Whole Solution

The data analyst

You bring data in, clean it with the verbs you already read, ask it questions in sentences, and end on a chart you can show.

  1. Import and clean with the text, number and list functions. built · see: String
  2. Host the data in a table or a data set and query it. built · see: Tables & data
  3. Match patterns across tables, numbers and time. built · see: Pattern matching
  4. Pivot, and draw: the plots come from the engine. Their human verdict is still owed. built · see: Graphics
  5. Ask Aïcha over the governed data store. specification · see: The estate, stage by stage
