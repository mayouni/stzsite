A course about anything, computed

Softanza for education

A course can be about anything, and every cell of it can compute with Softanza's twenty-eight areas. This page is for institutions and course designers: what the learning system is, what it has proved beyond programming, and the limits beside every claim.

A course is a folder

The learning system serves two different propositions. One is learning Softanza itself, which is the Learn section. The other, this page, is a capability of the platform: a course about any subject, written as plain-text chapters whose cells compute with the platform's areas and judge their own results. A learner's progress is a text file that can be read forever.

  1. Chapters and exercises. A chapter is text with cells that run; an exercise is a promise checked by running the learner's program.
  2. Worlds and skills. A world is the setting the examples reason over: a restaurant, a cooperative, a school. A skill is a unit with its question, three levels and the guard that is its evidence.
  3. Overlays and cohorts. An overlay adapts a course to an institution without touching it. A cohort is a folder of learners and their progress.

The designer's pages are teach or design courses and run a programme.

The proof beyond programming

The mathematics course is fifteen chapters in which every figure, from the number line to an exploration of data, is computed and judges its own picture. A geography course can compute with the map area, a statistics course with the statistics area. The elementary introduction and its four-language proof are on the book page.

The fifteen-minute demonstration

The library scripts a demonstration for education decision makers: zero install, their language, their world, nothing faked, the tutor, safe use of AI, all levels, ownership. It runs offline and ends on a line that must read "DEMO: 20 proved, 0 not proved". The command is on the Start page.

The limits, beside the claims

in construction French, Arabic and Hausa editions are drafts: none of 35 units has been reviewed by a native speaker. The cells run on a desktop and not yet in a browser. No institution has adopted the system yet. The full account, with the figures, is the record page. Nothing here is priced, and no offer for schools is made on this page.
