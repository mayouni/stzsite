Install

Three steps. Nothing is installed in the sense of an installer: one folder, copied, and the runtime that runs it.

1. Get the repository.

git clone https://github.com/mayouni/stzlib.git
cd stzlib/libraries/stzlib

2. Get the runtime, version 1.27.0, the one these pages were run with, from ring-lang.net(opens in a new tab). Starting the runtime with no argument prints its version, so you know it is there. The Zig engine ships as compiled libraries for Windows and builds for Linux and macOS from source; the repository says how.

3. Write the first program. In the folder libraries/stzlib, create a file first.ring whose first line loads the library, then the program of the next section:

load "stzLib.ring"

Run it from that folder:

ring first.ring

The first run takes about seven seconds, because the library and its engine load.

The course reader

The reader is a page of this site: open the reader. It was built from the library on 2026-09-30, and the Learn page says how to learn with it, step by step. To rebuild it yourself, from your copy of the repository:

cd libraries/stzlib/base/education/tools
ring build_reader.ring reader.html

run on 2026-09-30 at 23:02: "15 of 15 chapters, 3 of 3 world pages", every edition green, in 3 minutes 22 seconds

And to play the fifteen-minute demo for decision makers, whose last line must read "DEMO: 20 proved, 0 not proved":

cd libraries/stzlib/base/education/demo
ring demo.ring rehearsal

run on 2026-09-30 at 23:10, in 49 seconds, 20 proofs out of 20

Write

Questions, defect reports and proposals go through the issues of the GitHub repository(opens in a new tab). A security flaw is reported privately through the repository's security advisories, as its SECURITY.md(opens in a new tab) says. An edition of the course in your language starts with a folder of plain-text chapters: the Learn page says how the course's court will judge it. For the enterprise edition, write through the same issues: the Editions page says what it contains.
