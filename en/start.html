Install

The Zig engine ships as compiled libraries for Windows and builds for Linux and macOS from source; the platform's runtime is described in the repository. There is nothing to install in the sense of an installer: one folder, copied.

git clone https://github.com/mayouni/stzlib.git
cd stzlib/libraries/stzlib

A script placed in the libraries/stzlib folder loads the library with one line; the runtime that launches it, and its version, are the ones the repository names.

The first narration

A narration is a document that tells a part of the library as a story, in code written to be run as it is read. Start with the mental model(opens in a new tab), then the agents that cannot hurt you(opens in a new tab); both open on GitHub. The course reader

The reader is a page of this site: open the reader. It was built from the library on 2026-09-30, and the Learn page says how to learn with it, step by step. To rebuild it yourself, from your copy of the repository:

cd libraries/stzlib/base/education/tools
# run build_reader with the repository's runtime:
#   build_reader reader.html

run on 2026-09-30 at 23:02: "15 of 15 chapters, 3 of 3 world pages", every edition green, in 3 minutes 22 seconds

And to play the fifteen-minute demo for decision makers, whose last line must read "DEMO: 20 proved, 0 not proved":

cd libraries/stzlib/base/education/demo
# run demo with the repository's runtime:
#   demo rehearsal

run on 2026-09-30 at 23:10, in 49 seconds, 20 proofs out of 20

Write

Questions, defect reports and proposals go through the issues of the GitHub repository(opens in a new tab). A security flaw is reported privately through the repository's security advisories, as its SECURITY.md(opens in a new tab) says. An edition of the course in your language starts with a folder of plain-text chapters: the Learn page says how the course's court will judge it. For the enterprise edition, write through the same issues: the Offering page says what it contains.
