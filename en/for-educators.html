For an educator or an author

You teach, design courses or write about code: everything here runs, in your learners' language.

Your path

Every step carries its stage, in the words of the Estate page: built, in construction, specification, designed, named.

The educator

You turn what you know into units a learner can run, and you can say what a learner has proved, with the limits of that claim beside it.

  1. Write knowledge units as plain-text knowledge files. built · see: Teach, or design courses
  2. Give the learner a tutor that asks the questions, Aïcha. named · see: The estate, stage by stage
  3. Let the learner climb the ladder from explorer to master, each level earned by a project a guard checks. built · see: What is proved
  4. Add a ludic layer in a game file. designed · see: Education

The linguist and the knowledge architect

You declare the domain and its information architecture, and the library gives you a deterministic model of it, with no neurons, that answers from the graph and says why.

  1. Declare the domain in a closed file whose fixtures a court judges. built · see: Documentation system
  2. Gather a corpus with the text and list structures. built · see: NLP & linguistics
  3. Build a knowledge graph and its ontology. built · see: Natural, and executable
  4. Ask the deterministic model of the domain: every answer a lookup in the graph, with its reason. built · see: Wise coding
  5. Have Aïcha speak the domain. named · see: The estate, stage by stage

The author

You write an article whose code is real, and you publish it with the date it was run, in the languages your readers read.

  1. Take the article as the unit: prose and code in one file. built · see: Narrations
  2. Have a test reader run it as a tour, block after block. in construction · see: Narrations
  3. Prove a book chapter in four languages. built · see: Course
  4. Publish with the run date and the commit beside each block. built · see: A Guided Path to Problem-Solving: The Softanza Mental Model
