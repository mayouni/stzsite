Where it runs, and what it talks to

Reach

The platforms the engine runs on, the languages it can call, and the ports a solution reaches the world through. What is built, and what is not.

  • Platforms. Windows today. A Linux build of 85 of the engine's 89 modules exists on a working branch. A browser target takes a list of groups at compile time. A platform profile can name Windows, a Linux server, Android and a small board at once. in construction · see the architecture
  • External languages. Seven runtimes can be called, and foreign code can be pasted. built · see seven languages, one door
  • The polyglot seam. The engine has a plain C interface that any language can call, and it reads Python and JavaScript into the same code graph. built (the seam) · in construction (the experience)
  • Ports to the world. About twenty service ports with sandboxes: HTTP, data, blobs, mail, text messages, an AI model, payments, a registry, sign-in. built · see the host
  • Formats. Text formats are read and written: CSV, JSON, XML, HTML, archives, folders. Office formats are not read yet. built (text) · named (office formats)

in construction The counts are readings of the library and the engine's build file by an outside assessment on 2026-10-07; nothing was built on Linux for this page.
