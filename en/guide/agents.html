Agents & conversation

Softanza does not try to build a safe agent; it builds a safe world and lets ordinary agents work inside it.

The functions, by what they do

Testing and checking

  • CheckRules The uniform graph-owned verb: this graph checks ITSELF against its guardrails, in the unified finding shape (so an stzRuleReport can Collect it exactly like any other graph). Same findings as the object rule set. in stzAgentGraph
  • IsFluencyNeural TRUE only when neural fluency was asked for AND a model is really loaded -- so a caller can never mistake the floor for the upgrade. in stzConversation
  • IsValid what it says in stzAgentDeclaration

Replacing and setting

  • SetReactor Share another host's loop (e.g. an stzAppServer's) instead of owning one -- "the agent host is the same host". in stzAgentHost
  • SetPriority Higher runs first in a pass. Ties break on registration order, so the order is total and reproducible whether or not priorities are set. in stzAgentHost
  • SetActionBudget One agent acting in a loop floods everything downstream of it -- the cascading failure. A budget caps the ACTIONS (skill firings: what causes effects) an agent may take in a sliding window. An agent that exceeds it is QUARANTINED, not merely slowed: a runaway is a containment event, it stays stopped until an effectful actor releases it, and the reason says how far over it went. Both pumps account. in stzAgentHost
  • SetRetirementGovernance The governance whose decommission contract gates Retire(). NOTE: the stored @oGov is a COPY (governance is pure Haro lists -- no shared engine handle), so the decommission contract MUST be declared and fulfilled THROUGH THE HOST (below), which mutates this live copy. Fulfilling on the caller's original would leave the host's copy stale (the Haro aliasing doctrine). in stzAgentHost
  • SetGoal THE GOAL: one contract, accepted explicitly, then MONITORED -------- A conversation has exactly ONE goal. It is not assembled from inside the session -- it is BUILT as a stzGoal and HANDED OVER; from then on the conversation is accountable for it and watches it until it is FULFILLED (no gaps left in the space) or REVOKED (abandoned, with a reason). No goal = no loop: the elicitation is goal-driven, so asking without one REFUSES rather than inventing something to ask (LAW 3). in stzConversation
  • SetFluency fluency: a real upgrade when a model IS loaded, else the floor in stzConversation
  • SetCheckpointTTL G7 checkpoints, with a TTL ---------------------------------------- A refusal reaches a human -- but a checkpoint nobody cleared should not haunt the session forever. TTL(n) lets one LIVE for n turns; 0 (the default) means it never expires. Nothing is deleted: AllCheckpoints() still holds the full record -- expiry is about what still NEEDS a human. in stzConversation
  • SetActor Stamp the twin's actor so every rehearsed operation carries WHO proposed it -- the plan's narration then reads as a history with authors, not a list of anonymous changes. in stzAgentWorkbench
  • SetSkillFrom the LLM body is an stzLLMFunction (typed-or-refuse, budgeted, memoized -- R4 G3). The agent proposes through it. in stzLLMAgent

Adding

  • AddPIActor nodes (the capability lattice + taint colours) in stzAgentGraph
  • AddSkill a skill may declare the governed action it performs; if it does, the agent asks stzGovernance.MayProceed BEFORE running it in stzPIAgent

Converting

  • ToAgent from declaration to running agent ------------------------------ The valid declaration, built onto the classes that already exist. Nothing new runs; this only assembles. in stzAgentDeclaration

Reading and writing

  • Save persistence (*.zcnv) in stzConversation
  • ReadAgents loading -------------------------------------------------------- Read every agent file in the folder. Returns the number ACCEPTED; whatever was refused is in Refusals(), never swallowed. in stzAgentFolder

Walking and applying

  • RunFor Drive the loop for nMs, ticking due agents. The inter-tick wait is a REAL libuv timer awaited on the engine loop thread (falls back to a Haro sleep only when no reactor DLL is present -- LAW 2). in stzAgentHost
  • RunToQuiet Run until every supervised agent reaches fixpoint (a full pass with zero firings) or the cap is hit -- the cascade at host level. in stzAgentHost
  • Apply run only when the precondition holds; VERIFY the result before reporting success. Returns [ :ran, :verified, :why ]. in stzAgentSkill

The explanations are the ones the library gives of itself, read from its documentation comments on 2026-10-01 04:14, from the library at commit 0e72e2e2c, by the library's own stzSelfDoc over 635 class sources.
