Replacing and setting

  • SetArgs configuration in stzSystemCall

  • SetParams configuration in stzSystemCall

  • SetTarget Set the build target -- a stzSystemProfile (a deployment system), a friendly name (:LinuxServer, :ESP32), or a raw Zig triple ("x86_64-linux-gnu"). in stzBuilder
  • SetRingRoot Haro parts: lower to C, then compile through Zig in stzBuilder
  • SetKind the access config (Q-fluent: chainable via the ...Q suffix) in stzDeploymentSite
  • SetAuthRef auth is EITHER a plain reference string (e.g. "env/DEPLOY_KEY", back-compat) OR a stzSecret. When it is a secret, the site stores the OBJECT and displays only its redacted descriptor -- the key never lands in Config/ConfigJson. in stzDeploymentSite
  • SetCapacity what the host PROVIDES (its capacity). For a real host it is discovered via the provider API; for a fixed host it is declared here. in stzDeploymentSite
  • SetProvider name a provisioning provider -> this host can be CREATED/resized to meet a requirement (IaC-style), not just deployed to. in stzDeploymentSite

Adding

  • AddArg configuration in stzSystemCall
  • AddSource the declarative spec (fluent) in stzBuilder
  • PushWorld == 5. REGISTRY + ENFORCEMENT =========================================== in stzPlatform
  • AddCapability Request a capability for the attached world: oPlat.AddCapabilityQ(:camera).SetPurposes([ :scan-dish-photo ]) in stzPlatform
  • AddApp the apps in stzPlatformProfile
  • AddDevice a firmware part's DEVICE model (pins + an automation rule) ------- pins: [ [ pinNo, label, role, value ], ... ] role = "sensor" | "actuator". in stzAppTopology
  • AddDataset define the model (Q-fluent) ------------------------------------- a named dataset -- the solution's real domain data. A menu dataset is [ [ name, desc, price ], ... ]; an orders dataset is [ [ dish, qty ], ... ]. in stzAppTopology
  • AddWasm Add a wasm part -- a prebuilt .wasm path, or a stzBuilder (which is built). in stzWebBundle

Splitting and extracting

  • Parts delegating reads into the owned profile in stzPlatform

Converting

  • ParseOutputAsLines "string" type needs no conversion in stzSystemCall
  • ConvertOutputByType return type control in stzSystemCall
  • ParseOutputAsNumber return type control in stzSystemCall
  • ToCommand The full command line, as one string (rehearsable -- see it before you run it, the way the twin shows a plan before it commits). in stzBuilder
  • FromString Parse .stzsystem text into this profile. Defaults the role to deployment (a declared target) unless the text says otherwise, and fills class-default capabilities when no capabilities line is present. in stzSystemProfile
  • ToStzSystem the .stzsystem format (Law 1: a domain has a format) in stzSystemProfile
  • AsRuleGraph Project parts AND services into one graph, so a rule can ask the question neither side can answer alone: does a part that is BOUND TO A SITE (i.e. destined for production) depend on a service that is still a fake? See stzServiceRuleSet. in stzDelivery
  • ToStzPlatform the .stzplatform format in stzPlatformProfile
  • To Declare the deployment target (a friendly token or a stzSystemProfile). in stzAppProfile
  • ToBytes ToBytes: hex-decode the 32 hex chars (sans hyphens) into a list of 16 byte values. Pure Haro -- no engine call needed. in stzUUID

Reading and writing

  • OpenFile utilities in stzSystemCall
  • LoadFrom Read a .stzsystem file INTO this profile (the mirror of Save). in stzSystemProfile
  • ReadError wait / kill) in stzProcess
  • ReadOutput Reads the next available chunk of the child's stdout. Blocks until at least one byte arrives, or returns "" at end of stream. This is the STREAMING read -- call it in a loop. in stzProcess
  • ReadStderr wait / kill) in stzProcess
  • ReadErrorAll wait / kill) in stzProcess
  • ReadOutputAll Reads the child's stdout to the end, returning all of it. in stzProcess
  • OpenSession Returns a session token, or "" (Why() explains) on refusal. The secret is verified by re-deriving with the stored salt + rounds and a CONSTANT-TIME compare (StzEngineCryptoConstEqual). in stzPlatform
  • OpenCommonsOn == 3. THE COMMONS RUNTIME ============================================== Identity / sessions / messaging / stores over an OPEN stzDatabase. (The stored object shares the engine handle -- live; keep the original open while the platform runs.) in stzPlatform

  • Execute main execution in stzSystemCall

  • RunSilently silent execution in stzSystemCall
