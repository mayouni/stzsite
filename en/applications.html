What you build with it

Applications

With Softanza you build applications: you declare a world, and it runs. This page maps what holds that up, plane by plane, with each plane's stage, and says which surfaces exist today.

An application is a living world

An application, in Softanza, is a world of meaning and not a stack of screens. It is made of a domain, which is the things in it and their truths; a life, which is what it does and what it wants; and a body, which is where it endures. It is met by being seen, engaged, tuned and reached. A platform is then a constellation of such worlds, told on the platform of platforms page.

The application layer carries no name of its own. It is a part of the foundation and not a kind of product, so the site says what it is and then shows how.

The planes that hold it up

  1. The world and the constellation. The constructs that declare a world and join worlds. built · 7 guards · see platform of platforms
  2. The operational envelope. Generates the shells, holds the capability seam under governance, the commons and the registry. built · 3 guards · see platform of platforms
  3. The host. A host driven by the engine's reactor, and the live back end every part of a solution shares. built · 11 guards · see the host
  4. The scale plane and the services. Nodes, supervision, and the dependencies a solution can virtualise: HTTP, data, mail, text messages, payments, a language model, sign-in. built · 35 guards · see the host
  5. Delivery. Define, emulate, deploy, provision. built · the deployment guard, 45 of 45 · see from the editor to the device
  6. Agents hosted inside the application, and the life of the world. built · see agentic
  7. The declarative interface plane. An interface authored as text and drawn by a native renderer. in construction · see surfaces
  8. The store. A governed store beneath a world's body. in construction · see the store

Every stage here is read from the guards that judge each plane, not from the status documents, which describe an older state. Guard counts are those of the library at the commit read by an outside assessment on 2026-10-07.
