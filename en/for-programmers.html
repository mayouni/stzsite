Your path

Every step carries its stage, in the words of the Estate page: built, in construction, specification, designed, named.

You write the application you were asked for, and Softanza is the part of it that reads like a sentence, is correct in every script, and scales from one value to many cores.

  1. Learn the grammar of the function forms: a name is a sentence, so one verb teaches its whole family. built · see: Writing
  2. Reach for a pattern language where the problem is a string, a list, a number, a table or a time. built · see: Pattern matching
  3. Declare a world with stzApp when the program becomes an application. built · see: Your First App with stzApp: A World That Lives, and Wants
  4. Choose the width of the engine for the load: one value, a batch, several cores, the graphics card. built · see: GPU
  5. Write it all in Haro, the language that follows. in construction · see: Platform
