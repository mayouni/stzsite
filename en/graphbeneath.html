One structure under every domain

One graph beneath every domain

Beneath every domain is one graph. Code, workflows, knowledge, schemas and the declared world are the same structure, queried and drawn the same way.

  • The second largest domain of the library. The graph domain holds 37 files and 65,522 lines of code, counted from the library at commit 4a184e6f0.
  • Rules that see the whole picture. A rule is a rule over a graph, and one court judges rules over code, workflows, organisations and agents. built · see rules as graph rules
  • The graph is the product; the layout is a view of it. A picture of a graph is drawn from the graph, never the other way round. built · see the diagramming area
  • The declared world is a graph. The symbol table of a declared world is a graph, so the same queries answer about code and about the world. built · see the world

The Softanza way One structure, queried and drawn the same way, means that what you learn about a graph in one domain you have learned in all of them.

Sources: the article the graph as a computational foundation. The file and line counts are read by the depth page's tool.
