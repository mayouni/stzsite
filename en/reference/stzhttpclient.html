stzHttpClient

45 own methods · 0 forms written with extensions, listed under their method · Also inherits from stzNetwork (7)

the source: base/network/stzHttpClient.ring(opens in a new tab) · All classes · The area reference: Concurrency & distribution

stzHttpClient is the client side of the web: GET and POST, forms, downloads, many requests at once, authentication in every common scheme, and the timeouts, proxies and certificates a real network demands, each a setting you can read back.

Configure once, SetHeader, SetCookie, SetBearer(token), SetAuth with Basic by default or digest through SetAuthType, SetClientCert for mutual TLS, SetProxy, FollowRedirects, VerifySSL, AcceptGzip, and then speak: Get, Post, PostForm, DownloadFile, Response and its accessors. GetMany runs a batch of GETs in parallel, one thread per address, and returns them together. Timeouts are the engine's own, SetConnectTimeout, SetRequestTimeout, with process-wide defaults, and PoolStats and Shutdown show and release the keep-alive pool.

Tracing is built in: StartTrace() attaches a fresh W3C trace context to the request and returns the header value to record, SetTraceParent continues one that arrived, so a call across services can be followed from end to end.

It serves any program that talks to another service, an API, a download, a webhook, a health probe.
