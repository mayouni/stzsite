UtilizationCheck
The self-checks ------------------------------------------ The utilization law, checked for real: anchor-computed U vs the monitor's independently SAMPLED utilization gauge. From one set of anchors U = X*D/cores is an identity (no information); two independent measurements agreeing is evidence the measurement itself is sound. Returns [ :computed, :sampled, :consistent, :message ]; sampled = -1 when the gauge is not watched/sampled.
LittleN
N -- the average requests in flight IMPLIED by Little's law (X * mean R). What you should see if you counted concurrency.
LittleCheckAgainst
Compare the implied N with a concurrency you MEASURED elsewhere (e.g. a worker pool's InFlight()). Same-scale consistency: within a factor of 3 (floored at 0.05 -- tiny numbers agree).
