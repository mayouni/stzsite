stzTimeLine

87 own methods · 51 forms written with extensions, listed under their method

the source: base/datetime/stzTimeLine.ring(opens in a new tab) · All classes · The area reference: Internationalization

stzTimeLine is a stretch of time with things on it: points, which happen at a moment, and spans, which last, each with a label; and the questions a planner asks of them, what is at this moment, what lies between these two, what overlaps, what is blocked.

Open it on a start and an end, new stzTimeLine(:From = "2024-10-10", :To = "2024-10-22 16:40:00"), a time being added to a bare date. Place events: AddPoint("MEETING", "2024-03-15 10:00:00"), AddSpan("PROJECT", from, to), AddPeriod, AddMoment; the names are synonyms, so you say it the way you think it. Then ask: WhatsAt(moment) lists what is live then, a point or a span; PointsBetween and SpansBetween cut a window; SortedPoints and SortedSpans put them in order; HasOverlaps says whether two spans collide; Duration, Summary, Content describe the whole.

A blocked span is a rule the timeline enforces: AddBlockedSpan("BLACKOUT", from, to), and IsBlocked(moment) refuses an event inside it, a span partly inside being reported as such. Labels can be found, renamed and removed, and the timeline shows itself as text.

It serves a project plan, a schedule of releases, a history of incidents, a campaign calendar, an audit of what happened when, and it reads its dates through stzDateTime, so any form that class understands is accepted here.

The most expressive uses

Four methods that show what the class is for; every example was run inside the library.

WhatsAt

A moment asked what is live then: a meeting, two spans, and nothing at all later.

oTimeLine = new stzTimeLine(
	:Start = "2024-01-01 00:00:00",
	:End = "2024-12-31 23:59:59"
)
oTimeLine {
	AddPoint("MEETING", "2024-03-15 10:00:00")
	AddSpan("PROJECT", "2024-03-01 00:00:00", "2024-05-31 23:59:59")
	AddSpan("CAMPAIGN", "2024-03-10 00:00:00", "2024-03-20 23:59:59")
}
? @@NL( oTimeLine.WhatsAt("2024-03-15 10:00:00") )
? @@( oTimeLine.WhatsAt("2024-02-15 12:00:00") )
#--> [
#--> 	[ "MEETING", "point" ],
#--> 	[ "PROJECT", "span" ],
#--> 	[ "CAMPAIGN", "span" ]

PointsBetween

A window cut from the year, and the events inside it.

oTimeLine = new stzTimeLine(
	:Start = "2024-01-01 00:00:00",
	:End = "2024-12-31 23:59:59"
)
oTimeLine {
	AddPoint("JAN_EVENT", "2024-01-15 10:00:00")
	AddPoint("FEB_EVENT", "2024-02-15 10:00:00")
	AddPoint("MAR_EVENT", "2024-03-15 10:00:00")
	AddPoint("APR_EVENT", "2024-04-15 10:00:00")
}
? @@( oTimeLine.PointsBetween("2024-02-01 00:00:00", "2024-03-31 23:59:59") )
? oTimeLine.MomentsBetween("2024-02-01 00:00:00", :And = "2024-03-31 23:59:59")
#--> [ "FEB_EVENT", "MAR_EVENT" ]
#--> FEB_EVENT
#--> MAR_EVENT

AddBlockedSpan

A blackout declared, and an event inside it refused with a reason.

oTimeline = new stzTimeLine("2024-01-01", "2024-12-31")
oTimeline.AddBlockedSpan("BLACKOUT", "2024-08-01 00:00:00", "2024-08-08 23:59:59")
if oTimeline.IsBlocked("2024-08-05 14:30:00")
	? "Cannot add event during blackout"
	#--> Cannot add event during blackout

ok
if oTimeline.IsSectionBlocked("2024-08-07", "2024-08-10")
	? "Span partially blocked"
	#--> Span partially blocked

ok

o1 = new stzTimeLine(:From = "2024-10-10", :To = "2024-10-22 16:40:00")
