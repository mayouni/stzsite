AddQ()

Same as Add: Add the given number to this one (mutating). For a copy, use Added.

The forms of this verb

Add · AddQ · Added

oMix = new stzNumber("1/4")
oMix.Add("0.25")

? oMix.Content()

? oMix.Representation()
# ...and exactly
