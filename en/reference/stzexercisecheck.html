stzExerciseCheck

13 own methods · 0 forms written with extensions, listed under their method

the source: base/education/stzExercise.ring(opens in a new tab) · All classes

stzExerciseCheck is a class that checks a learner's exercise. It runs the learner's program, compares what the program printed with what the exercise expects, and reports a verdict. The verdict says whether the exercise passed and why, in terms that the learner understands.

You need it in a course where exercises must be checked automatically. The example below defines an exercise that expects the output 3, the sum of 1 and 2. First it checks a program that prints 42: the verdict is 0, which means failed, and the reason says what the program printed. Then it checks a program that prints the sum of 1 and 2, and the verdict is 1, which means passed.

# an exercise: print the sum of 1 and 2
oNo = new stzExerciseCheck("demo", [ "3" ], "? 42", [])

? oNo.Passed()
#--> 0

# and it says what it printed, instead of only no
? StzFindFirst("It printed: 42", oNo.Why()) > 0
#--> TRUE

oYes = new stzExerciseCheck("demo", [ "3" ], "? 1 + 2", [])
? oYes.Passed()
#--> 1
run in the library on 2026-10-21

The class never reveals the expected value. The reason names what the program printed and what is still missing, and not the answer.

The class also keeps the evidence that a progress record needs: what was run, when, and a hash of it, which is a short fingerprint that changes when the text changes. It keeps the output, the error and the exit code, which is the number that a program returns when it ends.

Use it in the tutor of the course, whose rule is to ask and never to give the answer, and in every exercise that proves itself by refusing every wrong answer and accepting every right one.
