stzSystemCall

52 own methods · 27 forms written with extensions, listed under their method

the source: base/system/stzSystemCall.ring(opens in a new tab) · All classes · The area reference: System programming

Runs a program and gives back what it said: its output, its error stream and its exit code, each separately, with the arguments passed as a list and never through a quoted shell string.

The program and its arguments are named, or a command line is handed over to be parsed; a timeout is set; what to capture is chosen, the output, the error, and whether a console shows. The call runs once and answers with all three channels together. It used to run twice to collect them, and the double execution was found and closed.

The output can be converted on the way back, to a number or to a list of lines, so a caller that wants a count receives a count. Running by argument list rather than by a shell string is what makes a filename with a space, a quote or a non-ASCII letter arrive intact. It serves a build step, a conversion through an external tool, a system query, a test that drives another process, and anything else a program must delegate to the machine it runs on.
