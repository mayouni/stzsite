RawCallEntries
The UNRESOLVED call targets, [ class, method, callee, line ] -- every identifier called in a method body, builtins included. CallEdges() keeps only calls to DEFINED methods (so it drops builtins like substr); a rule like engine-first needs to SEE the builtin calls, so it reads these. The line is the CALL SITE, and a `def substr(` is a definition (not harvested here), so this distinguishes a call from a definition -- which a text scan of "substr(" cannot.
