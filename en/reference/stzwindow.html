Resize from code. The size lands at the next Poll(), which is also where the swapchain reconfigures -- so this drives exactly the path a dragged window edge drives, and that is why it exists: without it the resize path could only ever be tested by a person with a mouse.QCSXTZZZIBWU

DeltaTime
Seconds since the previous Poll(). Multiply speeds by this and motion stops depending on how fast the machine happens to be -- the one number that separates an animation from a slideshow.no extension

KeyDown
HELD vs PRESSED, and why a loop needs both: KeyDown answers "is it down right now" -- true every frame you hold it, which is what movement wants. KeyPressed answers "did it go down since the last Poll" -- true exactly once per physical press, which is what a command wants. Written with only the first, pressing P once pauses and unpauses sixty times.no extension
