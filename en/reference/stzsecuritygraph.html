stzSecurityGraph

28 own methods · 0 forms written with extensions, listed under their method

the source: base/security/stzSecurityGraph.ring(opens in a new tab) · All classes · The area reference: Security & governance

stzSecurityGraph is a class that draws the security of a solution as a graph. A graph is a set of nodes joined by edges. The nodes are actors, tools, secrets, stores, sites and capabilities. The edges say who holds what, who may act as whom, and what a tool confers, meaning the right to do something that the tool gives.

You need it to audit an agent system or a deployment before a review, and to make a build fail when the drawing shows a problem. Questions become searches for paths. Can this actor reach anything effectful, meaning anything that changes something, through a chain of tools and delegations? What is the blast radius of this secret, meaning everything that is affected if it leaks? Where is the shortest path that confers a capability, and which cut closes it? A flag check sees one step. Reachability sees all the steps. Actors carry a posture: trusted, external or sandboxed. An actor whose posture no longer matches the recorded one is reported as tampered with.

The example below checks one of the rules of the graph. It adds a secret that is kept in no store, adds a site that references that secret, and collects the findings in a report. It prints whether the report has at least one warning (1) and whether it has at least one error (0).

oSG = new stzSecurityGraph("s")
oSG.AddSecret("inline")
oSG.AddSite("prod")

# a site that references a secret kept in no store
oSG.References("prod", "inline")

oRep = new stzRuleReport("sev")
oRep.Collect(oSG)

? len( oRep.Warnings() ) > 0
#--> TRUE

? len( oRep.Errors() ) > 0
#--> FALSE
run in the library on 2026-10-21

The graph checks itself, with rules of its own. A secret kept in no store is a warning. A way to an effect with no check on the way is an error. The findings join the single report of the library, which is stzRuleReport.

Use it for the audit of an agent system and of a deployment, before a review, as a drawing that can make a build fail.
