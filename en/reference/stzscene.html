It matters more than a reported number: `Project()` divides by the viewport, and the GUI plane's in-scene raycast reads the same size to turn a screen pixel into a ray. A face that still believed its construction size would send every click to the wrong place in a window the user had resized -- silently, since a wrong click looks like a working program doing something else.
