HasTrailingChars()

TRUE if the string ends with a repeated char run.

Basic examples (2)

Softanza
o1 = new stzString("12.4560000")
# there is a trailing run
? o1.HasTrailingChars()
# of four chars
? o1.HowManyTrailingChar()
# the char is 0
? o1.TrailingChar()
# ... confirmed
? o1.TrailingCharIs("0")
Output
1
4
0
1

run on 2026-10-02 04:24 inside the library at commit 0e72e2e2c; taken from 670_hastrailingchars.ring(opens in a new tab)

Softanza
o1 = new stzString(".....mmMm")
# case-sensitive: no trailing run
? o1.HasTrailingChars()
# ... so no trailing char
? o1.TrailingChar()
# case-insensitive: mmMm is a run
? o1.HasTrailingCharsCS(:CaseSensitive = FALSE)
# ... made of m's
? o1.TrailingCharCS(FALSE)
Output
0

1
m
