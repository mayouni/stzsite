stzSimilarity

11 own methods · 0 forms written with extensions, listed under their method

the source: base/number/stzSimilarity.ring(opens in a new tab) · All classes · The area reference: Numeric & optimization

stzSimilarity is a class that measures how alike two lists of numbers are, and how far apart they are. A list of numbers used this way is called a vector. The class computes the dot product, the cosine, the Euclidean distance and the Manhattan distance, on vectors of any length, and the unit vector of a direction.

You need it when something has been turned into a list of numbers and must be compared, for example two sentences turned into embeddings (lists of numbers that represent them). The example below computes four results. It prints the dot product of (1, 2, 3) and (4, 5, 6). It prints the straight-line distance from (0, 0) to (3, 4). It prints the Manhattan distance between (1, 2, 3) and (4, 6, 3). It prints the unit vector in the direction of (3, 4). The outputs are 32, 5, 7 and (0.60, 0.80).

oS = new stzSimilarity()

# 1*4 + 2*5 + 3*6
? oS.Dot([ 1, 2, 3 ], [ 4, 5, 6 ])
#--> 32

# from the origin to (3, 4)
? oS.EuclideanFromLists([ 0, 0 ], [ 3, 4 ])
#--> 5

# 3 + 4 + 0
? oS.ManhattanFromLists([ 1, 2, 3 ], [ 4, 6, 3 ])
#--> 7

# a vector of length one, in the same direction
? @@( oS.NormalizedList([ 3, 4 ]) )
#--> [ 0.60, 0.80 ]
run in the library on 2026-10-21

Each measure answers a different question. The dot product multiplies the vectors item by item and adds the results: 1*4 + 2*5 + 3*6 in the example. The cosine, which is between minus one and one, ignores the lengths of the vectors and asks only whether they point the same way. This is what a comparison of embeddings needs. The Euclidean distance is the length of the straight line between the two points. The Manhattan distance is the sum of the differences along each axis. A unit vector has length one. Forms for three dimensions exist for the common case.

It is the arithmetic under similarity search: finding the nearest neighbours of a vector, grouping a corpus, and comparing one sentence with another. Use it for anything that has been turned into a list of numbers and must be compared. To group points, use stzKMeans. To place a new point among labelled points, use stzKnn.
