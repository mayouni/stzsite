stzNeuralNetwork

9 own methods · 1 forms written with extensions, listed under their method

the source: base/learning/stzNeuralNetwork.ring(opens in a new tab) · All classes · The area reference: NLP & linguistics

stzNeuralNetwork is a small network you can build in a few lines and train to a task: dense layers with a named activation, a trainer with a learning rate, and a prediction, all in the engine, with no framework and no model file to fetch.

Declare the input width, new stzNeuralNetwork([ :Inputs = 2 ]), then add layers, AddDenseLayer(4, :Tanh), AddDenseLayer(1, :Sigmoid); give an stzTrainer a learning rate and train for as many rounds as it takes, 2,000 in the library's own example; Predict(inputs) answers. SetSeed fixes the initialisation, so a run is reproducible; NumberOfLayers, NumberOfInputs and Layers show what was built.

The classical test is XOR, which no single layer can learn and a network of two can: four points, four expected answers, a hidden layer of four units, and the trained network gets all four right. The trained weights can be written out with ExportToGguf, in the format the library's inference tier reads, so what was learned here can be loaded there.

It serves a lesson on how learning works, a classifier on a small table, a prototype before a larger model, and any case where a few hundred weights are the right size.

The most expressive uses

One method that shows what the class is for; its example was run inside the library.

AddDenseLayer

XOR learned: two layers, a learning rate, 2,000 rounds, four right answers.

aX = [ [0,0], [0,1], [1,0], [1,1] ]
aY = [ [0], [1], [1], [0] ]
oN = new stzNeuralNetwork([ :Inputs = 2 ])
oN.AddDenseLayer(4, :Tanh)
oN.AddDenseLayer(1, :Sigmoid)
oT = new stzTrainer()
oT.SetLearningRate(0.5)
oT.Train(oN, aX, aY, 2000)
# 00 -> 0
? oN.Predict([0,0])[1] < 0.5
#--> TRUE

# 01 -> 1
? oN.Predict([0,1])[1] > 0.5
#--> TRUE

# 10 -> 1
? oN.Predict([1,0])[1] > 0.5
#--> TRUE

# 11 -> 0
? oN.Predict([1,1])[1] < 0.5
#--> TRUE

# the loss went down
? oT.FinalLoss() < oT.LossHistory()[1]
#--> TRUE

# ...essentially to zero
? oT.FinalLoss() < 0.001
#--> TRUE

# one loss per epoch was recorded
? len(oT.LossHistory())
#--> 2000

# Why() still narrates
? StzFindFirst("trained 2000 epoch", oT.Why()) > 0
#--> TRUE
