stzSecret

18 own methods · 5 forms written with extensions, listed under their method

the source: base/security/stzSecret.ring(opens in a new tab) · All classes · The area reference: Security & governance

stzSecret is a class that holds the location of a secret value, never the value itself. A secret is a value such as a password or a key that must not leak. In every print, log and file, the class shows only a redacted descriptor, which is a description with the value hidden.

You need it when your program holds credentials and also hands text to a model or writes logs, and you must make sure the credential never appears there. The secret object can be passed around freely, and it can be read in plaintext in very few places.

You say where the secret comes from: an environment variable (a named value set outside the program), a file, a vault (a service that stores secrets) or, for development and tests only, a literal value, which is still redacted in every output. What can be read safely is the name, the kind and the locator. The locator is a pointer, such as a variable name or a path, and never the secret. The example below declares a secret read from the environment variable DEPLOY_KEY, and prints its descriptor and its locator.

o1 = new stzSecret("deploy-key")
o1.FromEnv("DEPLOY_KEY")

# what any display or file sees
? o1.Descriptor()
#--> <secret 'deploy-key' (secret) from env:DEPLOY_KEY>

# where the value lives, which is not the value
? o1.SourceLocator()
#--> DEPLOY_KEY
run in the library on 2026-10-20

Reading the plaintext is possible through exactly one entry point, and a permission check governs it. The check asks whether this actor may read the secret. Only an actor that has effects and is not sandboxed may: the reveal succeeds for a trusted human and is refused for a language-model actor, which can only infer. A secret that comes from a vault is fetched through a resolver, a function passed at the moment of the reveal, after the actor check.

Use it in every program that holds credentials and also hands text to a model. The secret can sit inside a function that builds a prompt, a log line or a saved agent file without being what leaks.
