NumberOfOccurrence()

Same as NumberOfOccurrenceCS: NumberOfOccurrenceCS: count occurrences How many times the given item occurs in the list.

also written: HowMany · NumberOfDuplicatesOf

The extensions of this method

Each extension, and whether it exists for this method; an extension that exists combines with the others (FindSTCS).

Extension
Exists
What it adds · The names
Q
no
does what the method does, then returns the object, so the call can be chained
QQ
no
chains on the next, more specific type of object (the Q ladder)
QQQ
no
chains on the most specific type of object (the Q ladder)
QRT
no
returns the result as an object of the requested type
CS
yes
takes a case-sensitivity flag · NumberOfOccurrenceCS
ST
yes
takes the position to start from (StartingAt) · HowManyST, NumberOfOccurrenceST
IB
no
takes bounds that are included (IncludingBounds)
XT
no
the extended form: more parameters than the base method
XTT
no
yet another extension: a further extended form, after XT
Z
no
includes the position in what it returns
ZZ
no
returns positions as sections, [start, end]
W
yes
selects by a condition · NumberOfOccurrenceW
WF
no

D
no
takes a direction, forward or backward (Directional)
F
no

Many
