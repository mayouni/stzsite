FindPreviousNthItem()

FindPreviousNthItem(n, :StartingAt = pos): the POSITION of the n-th item counting BACK from pos inclusive (pos-n+1).

Basic examples (1)

Softanza
o1 = new stzList([ "A1", "A2", "A3", "A4", "A5", "A6", "A7" ])
# findnextnthitem example 1
? @@( o1.FindNextNthItem(3, :StartingAt = 4) )
# findnextnthitem example 2
? @@( o1.NextNthItem(3, :StartingAt = 4) )
# findnextnthitem example 3
? @@( o1.FindPreviousNthItem(4, :StartingAt = 7) )
# findnextnthitem example 4
? @@( o1.PreviousNthItem(4, :StartingAt = 7) )
Output
7
"A7"
4
"A4"
