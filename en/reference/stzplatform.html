SetWorld
== 1. GENERATION ======================================================== SET the world this platform envelopes -- by HARVESTING its declarations into the platform's own records, right now. It does NOT hold the world: Haro copies an object into an attribute, so a held stzApp would be a dead snapshot the moment the caller touched it (see the aliasing note in the header). Call this AFTER the world is declared. The world is ASKED through its own accessors -- a platform never reaches into another object's attributes. (A constellation ADDs many worlds; a platform SETs its one.)
Generate
Generate(:all) or Generate(:web / :desktop / :mobile). Writes REAL shell files (one per declared Reach) and returns the list of written paths. Raises when there is no world, no reach, or an unknown reach surface (LAW 3: refuse, never stub).
