Your path

Every step carries its stage, in the words of the Estate page: built, in construction, specification, designed, named.

You declare a platform floor by floor, from the machine up to the organisation, and every floor is a text file you own with a judge beside it. This is the journey that crosses the whole vertical.

  1. Write the guarantee sheet: five systems the solution answers to (technical, social, ecological, economic, cultural), and the standing promises to the people. No solution has a five-row sheet yet. designed · see: Platform of platforms
  2. Model the solution and its targets, and write feature code in a deployment scope that refuses what the target forbids. built · see: From Dev to Deploy Without Leaving Your Editor
  3. Declare the machines and the cloud: a file per box, a file for the links and the one way between them. Built and emulated; the cloud is two and a half steps of six. built · see: Sovereignty
  4. Declare the data: an insert-only log, a chain verified on open, facts over time, a write as a proposal. Two rungs are built. specification · see: The estate, stage by stage
  5. Declare the governance and the security: the regime, the lattice of capabilities, the secret store, the guarantees each tied to a guard. built · see: Security
  6. Declare the worlds and the constellation in the organisation's own words: a world per person and device, the commons, the bonds, the norms, the roles. Built in the library; customers run it on web stacks. built · see: Platform of platforms
  7. Rehearse the whole and commit it: emulate on the twin, then deploy to production through a plan with rollback, by an actor that may commit. Live hosts are gated by infrastructure. built · see: Deploying to the Target Sites
  8. Put the agent in: its declaration, the knowledge file as its world, the empty effect set for a model. The agents are built; Aïcha is a name. built · see: Agents That Cannot Hurt You
  9. Operate and evolve: two slots so an update is a trial before a commitment. The witness that checks every machine's record is ahead, and assurance behind it is a name. built · see: Sovereignty
