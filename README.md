# stzsite — the Softanza website

**The Makers Platform of the Agentic Age. Born in Africa. Useful to the World!**

This repository is the public website of [Softanza](https://github.com/mayouni/stzlib): a static site,
plain HTML, CSS and a little JavaScript, generated by one Python script from Markdown files, with fonts and
images self-hosted so that a page opened from `file://` on a laptop with no internet renders exactly as it
does online. Every page has a French and an English edition. A presentation mode, `/tour`, sequences the
site as full-screen scenes.

The site's law: **every claim links to the file, the guard or the render that proves it; every product
carries its stage; every code block on the site was run on the night of publication, and its output sits
beside it.** A block that could not run is not shown.

## Layout

| path | what |
|---|---|
| `index.html` | the onboarding scene, both languages, the visitor's browser language picks |
| `fr/*.html`, `en/*.html` | the nine pages: why, platform, learn, govern, makers, products, africa, start, tour |
| `reader.html` | the Learning System reader, built by `base/education/tools/build_reader.ring` from the library |
| `deck-check.html` | lists every asset the tour needs and reports each as found or missing, from `file://` |
| `content/` | the sources: `home.html`, `deck-check.html`, `<lang>/<page>.md` |
| `assets/` | fonts (SIL OFL), images, stylesheets, scripts |
| `proofs/` | renders of every page at phone, laptop and projector widths, light and dark |
| `tools/build.py` | the generator; `tools/shoot.mjs` renders the proofs with headless Chrome over its DevTools protocol (Node 22, no dependencies) |
| `JOURNAL.md` | what was decided, what was verified, and who looked |

## Build

```
pip install markdown
python tools/build.py
node tools/shoot.mjs
```

The generated pages are committed, so a clone opens without a build. `build.py` also measures the contrast
of every text/background pair the stylesheet declares and fails under the WCAG 2 thresholds.

## Presentation mode

Open `fr/tour.html` (or `en/tour.html`). Arrow keys, space or a click advance; `n` toggles the presenter's
notes; `h` shows the site header; `Escape` opens the current scene as its page. The scene number is in the
URL, so every scene is also an address. Before presenting offline, open `deck-check.html` from the same
folder: nothing may read *missing*.
