## How the comparison is made {#rules}

The record of Softanza's own documents holds sixty-four comparison grids against the field, and a grid alone is a brochure's shape: in those grids Softanza's column carries almost only ticks and the others' columns a great many crosses. So the site compares by five rules, and holds itself to them wherever it names another tool.

<ol class="steps">
<li value="1"><b>Cite or do not publish.</b> Every claim about another tool cites its documentation or a run, with a date.</li>
<li value="2"><b>Both sides run.</b> A code pair runs both sides, in named release builds, each in its own idiom. <a href="code.html">The code</a> is the page that does.</li>
<li value="3"><b>Losses beside wins.</b> A loss is published with the win, in the same block and the same type.</li>
<li value="4"><b>Generous to the others.</b> Ratings of the others are generous and say so.</li>
<li value="5"><b>No number without its method.</b></li>
</ol>

<p class="proof"><b>designed</b> The comparison is made at the height of the platform on this page and at the height of a feature on the code page. A comparison at the height of each area of the Atlas, with the field's answer, Softanza's, and where the field leads, waits on a register of comparisons that the library does not hold as data yet.</p>

<p class="way"><span>The Softanza way</span> One stop. To cover these thirty rows in Python you assemble numpy, pandas, matplotlib, scikit-learn, nltk, cryptography, geopandas and a neural framework, each with its own release calendar and its own idea of a string. Here they are one engine, one vocabulary, one set of laws, and one Atlas that says plainly where the platform is still behind.</p>

## One folder, copied {#install}

There is no installer and no package registry. The repository is one folder; the engine ships as compiled libraries for Windows, and a Linux build of most of its modules is under way. A script placed in the library's folder loads everything with one line.

<pre>git clone https://github.com/mayouni/stzlib.git
cd stzlib/libraries/stzlib</pre>

The direction, stated as a direction: a Haro program compiled to one static binary that carries the engine with it. Today the platform runs from its folder with the runtime the repository names. The Start page walks through it in one hour.
