## The definition {#definition}

Aïcha is the Softanza agent, in the author's definition. It ships natively with the foundation. It is shippable in any solution by providing a knowledge base, and any customer can rebrand it as their own agent. It is omnipresent in Softanza as a first-class conversational interface to talk to or about the library and the applications built on it. And it is itself a programmable sovereign AI that anyone can make quickly, even without Softanza, from text files, a folder and one lightweight binary on any platform.

<p class="proof"><b>named</b> No product ships under that name today. There is no binary named after it, no folder contract in force, no surface a person types into, no charter, and no packaging. What follows separates the organs that exist from the product that does not.</p>

## The folder that would make an agent {#folder}

<pre>my-agent/
  agent.pia          who it is: name, kind, coverage, reversibility, schedule, governance, skills
  knowledge/*.zknw   what it knows: facts, relations, an ontology, rules
  skills/*.pia       what it can do: precondition, act, verification, effect
  charter.pset       what it refuses to become: a signed predicate set
  persona/           how it speaks: name, languages, tone, the brand
  lexicon/*.zdlm     the domain's own voice, when forged
  models/            optional local models and their checksums
  memory/            what it learns, as a governed graph with provenance
  transcripts/       the conversations, as records</pre>

The folder is written, not run. The binary that reads it would judge every file at load, answer from knowledge first with its reason, propose with a local model when one is present, never commit an effect without a governed actor, and leave a transcript.

## The coding agent, refinement first {#code}

<p class="proof"><b>designed</b> The industry's coding agents have good hands and the diff as their unit. A Softanza coding agent would change the unit: a typed refinement on a declared point, reviewed through the cascade it causes, shown before it lands; a five-stage gate; a workbench that holds the proposed version, so that only a governed actor commits; and the library's own knowledge, Ask and HowTo, instead of guessing, with the scenario guards as the court. A language model inside it would be one faculty, local, budgeted, and without the capability to act. The <a href="coding-agents.html">coding agents page</a> calls this door decided and not built, and it still is.</p>

Three conversations, one agent, once it exists: about the library, with and about an application, and as a customer's own agent.
