## A course is a folder {#folder}

The learning system serves two different propositions. One is learning Softanza itself, which is <a href="learn.html">the Learn section</a>. The other, this page, is a capability of the platform: a course about any subject, written as plain-text chapters whose cells compute with the platform's areas and judge their own results. A learner's progress is a text file that can be read forever.

<ol class="steps">
<li value="1"><b>Chapters and exercises.</b> A chapter is text with cells that run; an exercise is a promise checked by running the learner's program.</li>
<li value="2"><b>Worlds and skills.</b> A world is the setting the examples reason over: a restaurant, a cooperative, a school. A skill is a unit with its question, three levels and the guard that is its evidence.</li>
<li value="3"><b>Overlays and cohorts.</b> An overlay adapts a course to an institution without touching it. A cohort is a folder of learners and their progress.</li>
</ol>

The designer's pages are <a href="education-teach.html">teach or design courses</a> and <a href="education-programme.html">run a programme</a>.

## The proof beyond programming {#proof}

The mathematics course is fifteen chapters in which every figure, from the number line to an exploration of data, is computed and judges its own picture. A geography course can compute with the map area, a statistics course with the statistics area. The elementary introduction and its four-language proof are on <a href="book.html">the book page</a>.

## The fifteen-minute demonstration {#demo}

The library scripts a demonstration for education decision makers: zero install, their language, their world, nothing faked, the tutor, safe use of AI, all levels, ownership. It runs offline and ends on a line that must read "DEMO: 20 proved, 0 not proved". The command is on <a href="start.html#reader">the Start page</a>.

## The limits, beside the claims {#limits}

<p class="proof"><b>in construction</b> French, Arabic and Hausa editions are drafts: none of 35 units has been reviewed by a native speaker. The cells run on a desktop and not yet in a browser. No institution has adopted the system yet. The full account, with the figures, is <a href="education-record.html#limits">the record page</a>. Nothing here is priced, and no offer for schools is made on this page.</p>
