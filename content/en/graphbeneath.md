<ul class="narr">
<li><b>The second largest domain of the library.</b> The graph domain holds 37 files and 65,522 lines of code, counted from the library at commit 4a184e6f0.</li>
<li><b>Rules that see the whole picture.</b> A rule is a rule over a graph, and one court judges rules over code, workflows, organisations and agents. <span class="rx-src">built · see <a href="innovations.html#i34">rules as graph rules</a></span></li>
<li><b>The graph is the product; the layout is a view of it.</b> A picture of a graph is drawn from the graph, never the other way round. <span class="rx-src">built · see <a href="atlas/diagramming.html">the diagramming area</a></span></li>
<li><b>The declared world is a graph.</b> The symbol table of a declared world is a graph, so the same queries answer about code and about the world. <span class="rx-src">built · see <a href="world.html">the world</a></span></li>
</ul>

<p class="way"><span>The Softanza way</span> One structure, queried and drawn the same way, means that what you learn about a graph in one domain you have learned in all of them.</p>
