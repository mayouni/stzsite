<ul class="narr">
<li><b>Platforms.</b> Windows today. A Linux build of 85 of the engine's 89 modules exists on a working branch. A browser target takes a list of groups at compile time. A platform profile can name Windows, a Linux server, Android and a small board at once. <span class="rx-src">in construction · see <a href="architecture.html">the architecture</a></span></li>
<li><b>External languages.</b> Seven runtimes can be called, and foreign code can be pasted. <span class="rx-src">built · see <a href="polyglot.html">seven languages, one door</a></span></li>
<li><b>The polyglot seam.</b> The engine has a plain C interface that any language can call, and it reads Python and JavaScript into the same code graph. <span class="rx-src">built (the seam) · in construction (the experience)</span></li>
<li><b>Ports to the world.</b> About twenty service ports with sandboxes: HTTP, data, blobs, mail, text messages, a language model, payments, a registry, sign-in. <span class="rx-src">built · see <a href="host.html">the host</a></span></li>
<li><b>Formats.</b> Text formats are read and written: CSV, JSON, XML, HTML, archives, folders. Office formats are not read yet. <span class="rx-src">built (text) · named (office formats)</span></li>
</ul>

<p class="proof"><b>in construction</b> The counts are readings of the library and the engine's build file by an outside assessment on 2026-10-07; nothing was built on Linux for this page.</p>
