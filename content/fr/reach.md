<ul class="narr">
<li><b>Plateformes.</b> Windows aujourd'hui. Une construction Linux de 85 des 89 modules du moteur existe sur une branche de travail. Une cible navigateur prend une liste de groupes à la compilation. Un profil de plateforme peut nommer Windows, un serveur Linux, Android et une petite carte à la fois. <span class="rx-src">en construction · voir <a href="architecture.html">l'architecture</a></span></li>
<li><b>Langages externes.</b> Sept environnements d'exécution peuvent être appelés, et du code étranger peut être collé. <span class="rx-src">construit · voir <a href="polyglot.html">sept langues, une porte</a></span></li>
<li><b>La couture polyglotte.</b> Le moteur a une interface C simple que n'importe quel langage peut appeler, et il lit Python et JavaScript dans le même graphe de code. <span class="rx-src">construit (la couture) · en construction (l'expérience)</span></li>
<li><b>Ports vers le monde.</b> Une vingtaine de ports de service avec bacs à sable : HTTP, données, blobs, courriel, SMS, un modèle de langage, paiements, un registre, connexion. <span class="rx-src">construit · voir <a href="host.html">l'hôte</a></span></li>
<li><b>Formats.</b> Les formats texte sont lus et écrits : CSV, JSON, XML, HTML, archives, dossiers. Les formats bureautiques ne sont pas encore lus. <span class="rx-src">construit (texte) · nommé (formats bureautiques)</span></li>
</ul>

<p class="proof"><b>en construction</b> Les décomptes sont des lectures de la bibliothèque et du fichier de construction du moteur par une évaluation extérieure du 2026-10-07 ; rien n'a été construit sur Linux pour cette page.</p>
