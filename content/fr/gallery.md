title: La galerie
title_html: La <i>galerie</i>
kicker: Ce que dessine le moteur, et qui a regardé
lede: Les tests graphiques de la bibliothèque écrivent chacun une image. Une image peut être fausse d'une façon qu'aucun compteur ne voit : une province absente d'une carte, une étiquette sur une arête. Voici donc chacune, redessinée ce soir quand c'est possible, avec le script qui la fait et une place pour le verdict d'une personne.
description: La galerie Softanza : les images du moteur redessinées, comparées octet par octet à celles que la bibliothèque a gardées, chacune avec son script et une place pour le verdict d'une personne, et les images qui ne peuvent pas être redessinées dites telles.

<p class="proof"><b>en construction</b> La porte de perception de ces images est ouverte. Un modèle en a jugé certaines dans le passé, et l'avis d'un modèle n'est pas ici : seul le verdict d'une personne, avec son nom et la date, est imprimé. Les images qui n'ont pas été redessinées demandent des données qui ne sont pas dans le dépôt, une fenêtre sur un écran, ou un fichier que le script n'a pas pu lire ; chacune dit lequel.</p>
