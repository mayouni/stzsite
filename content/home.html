Des années de code écrit à la main, puis l'IA sous gouvernance

Years of hand-written code, then AI under governance

Softanza a été écrit à la main, pendant environ cinq ans, avant que les outils d'IA de programmation n'existent. Fin 2024, il comptait 1 697 commits d'un seul auteur, 348 000 lignes de bibliothèque et 63 000 lignes de tests, sans moteur encore.

Softanza was written by hand, over about five years, before AI coding tools existed. By the end of 2024 it held 1,697 commits by one author, 348,000 lines of library and 63,000 lines of tests, with no engine yet.

L'IA est venue en deux temps. Fin 2025, l'auteur a commencé à utiliser l'IA en collant lui-même ses résultats dans le code. En 2026, il est passé à Claude Code Desktop, et Softanza est devenu un produit d'abord IA : Claude Code écrit tout le code Zig et tout le code du runtime, et Mansour Ayouni gouverne les raffinements que l'IA apporte au code.

AI came in two steps. In late 2025 the author began pasting AI results into the code himself. In 2026 he moved to Claude Code Desktop, and Softanza became an AI-first product: Claude Code now writes all of the Zig code and all of the runtime code, and Mansour Ayouni governs the refinements the AI makes to it.
