Une seule plateforme : un moteur écrit en Zig pour le texte, les nombres exacts, les tables, les cartes, le son, les réseaux de neurones et les agents d'IA gouvernés.

One platform: one engine, written in Zig, for text, exact numbers, tables, maps, sound, neural networks and governed AI agents.

Déclarer, puis gouvernerVous déclarez votre monde dans une langue faite pour lui ; un tribunal le juge quand il tourne, et rien n'est cru sur parole. Des agents d'IA qui ne peuvent pas nuireUn agent d'IA propose, seul un acteur gouverné commet : trente-huit garanties, chacune liée à un garde. La preuve avant la promesseChaque bloc de code qui tourne a été exécuté avant la publication, les autres le disent, et chaque affirmation renvoie au fichier qui la prouve.
Declare, then governYou declare your world in a language made for it; a court judges it when it runs, and nothing is believed on trust. AI agents that cannot hurt youAn AI agent proposes, only a governed actor commits: thirty-eight guarantees, each tied to a guard. Proof before promiseEvery block of code that runs was run before publication, the others say so, and every claim links to the file that proves it.
