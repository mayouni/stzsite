Surfaces

Une application se rencontre sur une surface. Aujourd'hui le web est la voie de livraison des applications métier, et une interface native déclarative est en construction, les jeux d'abord. Le reste sont des directions, et la loi d'interface les juge toutes.

Ce qui existe aujourd'hui

Le web (construit)

Le plan de référence est net : le niveau web reste la voie de livraison des applications métier. Les applications qui tournent emploient des outils web, avec une boîte à outils embarquée et sans étape de construction, installées comme application sur un téléphone, ouvertes dans une enveloppe de bureau ou dans une enveloppe Android.

L'interface native (en construction)

Un moteur au-dessus des graphiques, avec une interface écrite de façon déclarative comme du texte, l'écriture de droite à gauche et l'accessibilité pour points forts. Son ordre d'attaque est les surfaces de scène et de jeu d'abord, et les logiciels métier pour opérateurs seulement quand l'accessibilité et les méthodes de saisie sont financées comme un travail de plusieurs années.

Ce qui est direction

  • Un terminal, pour les personnes et les agents qui y travaillent.
  • La voix : la synthèse vocale existe dans le moteur ; la reconnaissance vocale et la téléphonie non.
  • La messagerie, l'application déjà sur le téléphone d'une personne : racontée sur la page des conversations, conçue et surtout absente.
  • Les appareils : une machine déclarée comme du logiciel d'abord, sur la page de la souveraineté.

La manière Softanza La grammaire d'interface est fermée : une nouvelle surface ajoute des rendus et jamais des verbes. Chaque surface ici est jugée par la même loi d'interface, que ce soit une page, une fenêtre ou un fil de messages.

en construction Le moteur de rendu du plan natif et son arbre d'accessibilité sont lus dans les fichiers de la bibliothèque et ses huit gardes ; le plan a été lu et pas vu sur un écran pour cette page. L'enveloppe de téléphone empaquetée et la vue web de bureau sont absentes de ce que l'enveloppe génère aujourd'hui ; les applications qui tournent portent la leur.
