Lus dans le dossier doc/narrations du dépôt au commit 4a184e6f0. Chaque article est une page. Le 2026-10-08, chacun a été exécuté au nom de Haro dans la bibliothèque, bloc après bloc ; un bloc qui a tenu sa promesse le dit, les autres sont des illustrations. Le code des articles est du code Haro : là où un article a été écrit avant que la langue prenne son nom actuel, le nom a été changé et rien d'autre.
