Installer

Le moteur Zig est livré en bibliothèques compilées pour Windows et se construit pour Linux et macOS depuis la source ; l'exécutant de la plateforme est décrit dans le dépôt. Il n'y a rien à installer au sens d'un installateur : un dossier, copié.

git clone https://github.com/mayouni/stzlib.git
cd stzlib/libraries/stzlib

Un script placé dans le dossier libraries/stzlib charge la bibliothèque par une ligne ; l'exécutant qui le lance, et sa version, sont ceux que le dépôt indique.

La première narration

Une narration est un document dont chaque bloc de code s'exécute, et dont les sorties ne sont jamais stockées : ce que vous lisez a été produit en lisant. Commencez par le modèle mental, puis les agents qui ne peuvent pas vous nuire. Les 134 narrations sont dans doc/narrations.

Le lecteur du cours

Le lecteur est sur la page Apprendre, construit cette nuit. Pour le reconstruire vous-même, depuis votre copie du dépôt :

cd libraries/stzlib/base/education/tools
# lancer build_reader avec l'exécutant du dépôt :

Écrire

Les questions, les rapports de défaut et les propositions passent par les issues du dépôt GitHub. Une faille de sécurité se signale en privé par les avis de sécurité du dépôt, comme l'indique son fichier SECURITY.md. Une édition du cours dans votre langue, zarma ou autre, commence par un dossier de chapitres en texte brut : la page Apprendre dit comment le tribunal du cours la jugera.

Vérifier ce site hors ligne

Avant une présentation sans réseau, ouvrez deck-check.html depuis le dossier du site : la page charge chaque ressource dont la présentation a besoin et dit laquelle manque.
