Démarrer

Un dépôt public, une installation en deux commandes, un premier programme, le lecteur du cours comme page de ce site. Chaque commande de cette page a été exécutée le soir de la publication.

Le dépôt

Tout est au même endroit : la fondation, son moteur, ses gardes, ses narrations et son cours.

github.com/mayouni/stzlib

Installer

Le moteur Zig est livré en bibliothèques compilées pour Windows et se construit pour Linux et macOS depuis la source ; l'exécutant de la plateforme est décrit dans le dépôt. Il n'y a rien à installer au sens d'un installateur : un dossier, copié.

git clone https://github.com/mayouni/stzlib.git
cd stzlib/libraries/stzlib

Un script placé dans le dossier libraries/stzlib charge la bibliothèque par une ligne ; l'exécutant qui le lance, et sa version, sont ceux que le dépôt indique.

La première narration

Une narration est un document où chaque bloc de code s'exécute et où aucune sortie n'est jamais stockée : ce que vous lisez a été produit pendant la lecture. Commencez par le modèle mental, puis les agents qui ne peuvent pas vous nuire. Les 134 sont listées sur la page des narrations.

Le lecteur du cours

Le lecteur est une page de ce site : ouvrir le lecteur. Il a été construit depuis la bibliothèque le 2026-09-30, et la page Apprendre dit comment apprendre avec lui, étape par étape. Pour le reconstruire vous-même, depuis votre copie du dépôt :

cd libraries/stzlib/base/education/tools
# lancer build_reader avec l'exécutant du dépôt :
#   build_reader reader.html

Et pour jouer la démonstration de quinze minutes pour décideurs, dont la dernière ligne doit dire « DEMO: 20 proved, 0 not proved » :

cd libraries/stzlib/base/education/demo
# lancer demo avec l'exécutant du dépôt :
#   demo rehearsal

Écrire

Les questions, les rapports de défaut et les propositions passent par les tickets du dépôt GitHub. Une faille de sécurité se signale en privé par les avis de sécurité du dépôt, comme le dit son SECURITY.md. Une édition du cours dans votre langue commence par un dossier de chapitres en texte brut : la page Apprendre dit comment le tribunal du cours la jugera. Pour l'édition entreprise, écrivez par les mêmes tickets : la page Offre dit ce qu'elle contient.

Vérifier ce site hors ligne

Avant une présentation sans réseau, ouvrez deck-check.html depuis le dossier du site : la page charge chaque ressource dont la présentation a besoin et dit laquelle manque.
