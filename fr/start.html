Démarrer

Un dépôt public, une installation en trois étapes, un premier programme, le lecteur du cours comme page de ce site. Chaque commande de cette page a été exécutée le soir de la publication.

L'exécution, en clair Softanza tourne aujourd'hui sur sa face Ring, gardée pour que le code déjà écrit continue de fonctionner. Ring++ est le pont, en construction. Haro est la destination.

Le dépôt

Tout est au même endroit : la fondation, son moteur, ses gardes, ses narrations et son cours.

github.com/mayouni/stzlib

Public sous licence MIT depuis le 12 mars 2022. Les tickets, les avis de sécurité et tout l'historique y sont.

github.com/mayouni/stzlib(s'ouvre dans un nouvel onglet)

Installer

Trois étapes. Rien ne s'installe au sens d'un installateur : un dossier, copié, et l'exécutant qui le lance.

1. Prendre le dépôt.

git clone https://github.com/mayouni/stzlib.git
cd stzlib/libraries/stzlib

2. Prendre l'exécutant, version 1.27.0, celle avec laquelle ces pages ont été exécutées, sur ring-lang.net(s'ouvre dans un nouvel onglet). Lancer l'exécutant sans argument affiche sa version, ce qui montre qu'il est là. Le moteur Zig est livré en bibliothèques compilées pour Windows et se construit pour Linux et macOS depuis la source ; le dépôt dit comment.

3. Écrire le premier programme. Dans le dossier libraries/stzlib, créer un fichier first.ring dont la première ligne charge la bibliothèque, puis le programme de la section suivante :

load "stzLib.ring"

Le lancer depuis ce dossier :

ring first.ring

Le premier lancement prend environ sept secondes, parce que la bibliothèque et son moteur se chargent.

La première narration

Une narration est un document qui raconte une partie de la bibliothèque comme une histoire, en code écrit pour être exécuté au fil de la lecture. Commencez par le modèle mental(s'ouvre dans un nouvel onglet), puis les agents qui ne peuvent pas vous nuire(s'ouvre dans un nouvel onglet) ; les deux s'ouvrent sur GitHub. Pour voir une narration jugée bloc par bloc, ouvrez Repetition with Elegance, exécutée pour ce site : ses six blocs affichent ce qu'ils promettent. Les 134 sont listées sous Apprendre, dans Narrations.

Le lecteur du cours

Le lecteur est une page de ce site : ouvrir le lecteur. Il a été construit depuis la bibliothèque le 2026-09-30, et la page Apprendre dit comment apprendre avec lui, étape par étape. Pour le reconstruire vous-même, depuis votre copie du dépôt :

cd libraries/stzlib/base/education/tools
ring build_reader.ring reader.html

exécuté le 2026-09-30 à 23:02 : « 15 of 15 chapters, 3 of 3 world pages », chaque édition verte, en 3 minutes 22 secondes

Et pour jouer la démonstration de quinze minutes pour décideurs, dont la dernière ligne doit dire « DEMO: 20 proved, 0 not proved » :

cd libraries/stzlib/base/education/demo
ring demo.ring rehearsal

exécuté le 2026-09-30 à 23:10, en 49 secondes, 20 preuves sur 20

Écrire

Les questions, les rapports de défaut et les propositions passent par les tickets du dépôt GitHub(s'ouvre dans un nouvel onglet). Une faille de sécurité se signale en privé par les avis de sécurité du dépôt, comme le dit son SECURITY.md(s'ouvre dans un nouvel onglet). Une édition du cours dans votre langue commence par un dossier de chapitres en texte brut : la page Apprendre dit comment le tribunal du cours la jugera. Pour l'édition entreprise, écrivez par les mêmes tickets : la page Éditions dit ce qu'elle contient.

Vérifier ce site hors ligne

Avant une présentation sans réseau, ouvrez deck-check.html depuis le dossier du site : la page charge chaque ressource dont la présentation a besoin et dit laquelle manque.

La plateforme des artisans du logiciel à l'ère de l'IA. Née en Afrique. Utile au monde !

Chaque affirmation de ce site renvoie au fichier, au garde ou au rendu qui la prouve. Chaque bloc de code qui s'exécute a été exécuté le soir de la publication et sa sortie est à côté ; les autres le disent.

Les textes de ce site ont été rédigés avec un assistant d'IA, Claude, sous la direction de l'auteur ; le code, les exécutions et les chiffres viennent des dépôts. (Règle 99 de la constitution Zui : ce qui est fait par une machine le dit.)
