Agents et conversation

Softanza ne cherche pas à fabriquer un agent sûr ; il bâtit un monde sûr et y laisse travailler des agents ordinaires.

Les fonctions, par ce qu'elles font

Tester et vérifier

  • CheckRules The uniform graph-owned verb: this graph checks ITSELF against its guardrails, in the unified finding shape (so an stzRuleReport can Collect it exactly like any other graph). Same findings as the object rule set. dans stzAgentGraph
  • IsFluencyNeural TRUE only when neural fluency was asked for AND a model is really loaded -- so a caller can never mistake the floor for the upgrade. dans stzConversation
  • IsValid what it says dans stzAgentDeclaration

Remplacer et modifier

  • SetReactor Share another host's loop (e.g. an stzAppServer's) instead of owning one -- "the agent host is the same host". dans stzAgentHost
  • SetPriority Higher runs first in a pass. Ties break on registration order, so the order is total and reproducible whether or not priorities are set. dans stzAgentHost
  • SetActionBudget One agent acting in a loop floods everything downstream of it -- the cascading failure. A budget caps the ACTIONS (skill firings: what causes effects) an agent may take in a sliding window. An agent that exceeds it is QUARANTINED, not merely slowed: a runaway is a containment event, it stays stopped until an effectful actor releases it, and the reason says how far over it went. Both pumps account. dans stzAgentHost
  • SetRetirementGovernance The governance whose decommission contract gates Retire(). NOTE: the stored @oGov is a COPY (governance is pure Haro lists -- no shared engine handle), so the decommission contract MUST be declared and fulfilled THROUGH THE HOST (below), which mutates this live copy. Fulfilling on the caller's original would leave the host's copy stale (the Haro aliasing doctrine). dans stzAgentHost
  • SetGoal THE GOAL: one contract, accepted explicitly, then MONITORED -------- A conversation has exactly ONE goal. It is not assembled from inside the session -- it is BUILT as a stzGoal and HANDED OVER; from then on the conversation is accountable for it and watches it until it is FULFILLED (no gaps left in the space) or REVOKED (abandoned, with a reason). No goal = no loop: the elicitation is goal-driven, so asking without one REFUSES rather than inventing something to ask (LAW 3). dans stzConversation
  • SetFluency fluency: a real upgrade when a model IS loaded, else the floor dans stzConversation
  • SetCheckpointTTL G7 checkpoints, with a TTL ---------------------------------------- A refusal reaches a human -- but a checkpoint nobody cleared should not haunt the session forever. TTL(n) lets one LIVE for n turns; 0 (the default) means it never expires. Nothing is deleted: AllCheckpoints() still holds the full record -- expiry is about what still NEEDS a human. dans stzConversation
  • SetActor Stamp the twin's actor so every rehearsed operation carries WHO proposed it -- the plan's narration then reads as a history with authors, not a list of anonymous changes. dans stzAgentWorkbench
  • SetSkillFrom the LLM body is an stzLLMFunction (typed-or-refuse, budgeted, memoized -- R4 G3). The agent proposes through it. dans stzLLMAgent

Ajouter

  • AddPIActor nodes (the capability lattice + taint colours) dans stzAgentGraph
  • AddSkill a skill may declare the governed action it performs; if it does, the agent asks stzGovernance.MayProceed BEFORE running it dans stzPIAgent

Convertir

  • ToAgent from declaration to running agent ------------------------------ The valid declaration, built onto the classes that already exist. Nothing new runs; this only assembles. dans stzAgentDeclaration

Lire et écrire

  • Save persistence (*.zcnv) dans stzConversation
  • ReadAgents loading -------------------------------------------------------- Read every agent file in the folder. Returns the number ACCEPTED; whatever was refused is in Refusals(), never swallowed. dans stzAgentFolder

Parcourir et appliquer

  • RunFor Drive the loop for nMs, ticking due agents. The inter-tick wait is a REAL libuv timer awaited on the engine loop thread (falls back to a Haro sleep only when no reactor DLL is present -- LAW 2). dans stzAgentHost
  • RunToQuiet Run until every supervised agent reaches fixpoint (a full pass with zero firings) or the cap is hit -- the cascade at host level. dans stzAgentHost
  • Apply run only when the precondition holds; VERIFY the result before reporting success. Returns [ :ran, :verified, :why ]. dans stzAgentSkill
