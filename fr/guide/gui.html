Interface et réactif

Les déclarations Softanza font contrat ; le balisage que lit le moteur d'interface n'en est qu'une projection, générée et jamais écrite à la main.

  • IsStrictlyPlaced A box sits where its predecessors left it, so its POSITION is only claimed when it and every earlier sibling fix their own size. dans stzUiDocument
  • IsBeingRead TRUE when something has read the tree at least once -- which is the only evidence available in-process that a screen reader is there. dans stzScreenReaderBridge
  • CheckAndTick Drive the timer from the manager's poll loop. Returns isActive so the manager can prune completed one-shot timers. dans stzReactiveTimer

Remplacer et modifier

  • SetTime RmlUi's clock, driven by the caller -- so a test frame is deterministic instead of depending on when it ran. dans stzPanel
  • SetTextOf The difference is measurable, and the guard measures it: after a rebuild every string is generated again; after a set, only the ones that actually changed are. GenerateCalls() reports both. One element's words. The value is DATA -- it is escaped at the seam, so a model holding "<span>" cannot inject markup into a document the court already passed. dans stzPanel
  • SetStyleOf An EMPTY value removes the property, handing the element back to the stylesheet. Without that, a binding that had fired once could never be undone. dans stzPanel
  • SetBody == BODY (embodiment) ==================================================== SetBody() returns This; the brace assigns the body-cursor attributes (Graph_/Files/Keep_ -- note: the DSL keywords Graph and Keep collide with the Graph() accessor and the Keep(thing) flow verb, so the ATTRIBUTES carry a trailing underscore and BraceEnd reads whichever was written). dans stzApp
  • SetAutoConcludeDelay It used to take anything at all: -500 and "not a number" both went straight through to a timer deadline. A refused value leaves the delay ALONE rather than resetting it -- a setter that answers a value it dislikes by destroying a good one is its own defect. dans stzReactiveStream

Convertir

  • ToCanvas The panel as a picture, on the tier this machine can reach. A canvas is made, drawn into and answered -- so the caller gets ToSVG/ToPNG/ Show without assembling anything. dans stzPanel
  • FromWindow the conversions, named at the boundary ------------------------------ A window's pixels are the panel's when the panel fills the window, which is the case stzWindow.Draw arranges. Named anyway: the reader of a frame loop should see WHERE the space changes. dans stzPanel
  • FromTexture A panel hanging in a 3D scene is hit by a RAY, and what the caller has after the intersection is a texture coordinate. This is the whole of the in-scene input mapping (§6's tier): uv in, panel pixels out. v is flipped because a texture's origin is bottom-left and a panel's is top-left -- the one place that difference is stated, so no caller has to remember it. dans stzPanel
  • ToRml the projection ------------------------------------------------------ The RML this document means. The defaults here are §4b's table: every divergence G1 found is absorbed so the author never sees it. dans stzUiDocument
  • ToHtml THIS SHARES EVERY RULE WITH ToRml. The two projections differ only where stzUiProfile records a DIVERGENCE, and they ask the profile for the spelling rather than carrying their own copy -- which is the whole reason the profile had to become data. If the shared half ever forks, the fixture below is what says so. dans stzUiDocument
  • ToText the canonical print (round-trip fixpoint) dans stzUiDocument
  • ToFixture paNativeBoxes is [ [ name, x, y, w, h ], ... ] from the laid-out panel -- BoxOf() for every named element. dans stzUiDocument
  • ToJSON the tree as DATA ---------------------------------------------------- Rule 104: "what a screen reader can operate, an agent can operate." A tree that only a C++ adapter can read serves the first and not the second, so it goes out as JSON -- inspectable, diffable, assertable in CI, and the shape an adapter of any language can consume. dans stzAccessibilityTree

Afficher, dessiner et mettre en forme

  • BoxOf The laid-out box of one element: [x, y, w, h], in panel pixels. Empty when there is no such element -- an absence, not a raise, since asking about an element that may not exist is a fair question. dans stzPanel
  • DrawInto output -------------------------------------------------------------- Put the panel's triangles into a canvas. The canvas decides what happens next -- ToSVG() with no device, ToPNG() with one, a window, or a texture mapped onto a quad in a 3D scene. The panel does not know and must not care. dans stzPanel
  • RenderOf What one element's text would be, right now. Inspectable without touching the panel, which is what makes the substitution testable separately from the rendering. dans stzUiBindings
