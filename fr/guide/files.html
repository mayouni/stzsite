Fichiers et formats

On aborde un fichier selon ce qu'on veut en faire, et chaque format est analysé une seule fois, dans le moteur, par un analyseur dont les refus font partie de la sécurité.

Les fonctions, par ce qu'elles font

Tester et vérifier

  • AreFiles batch validation methods dans stzFolder
  • AreFolders batch validation methods dans stzFolder
  • IsSecurePath checking path security dans stzFolder
  • IsValid A document is valid if it parsed and yielded at least one element. dans stzHtml

Trouver

  • Find Find: minimal CSS-like dispatch (tag / #id / .class). Returns a list of stzHtmlNode handles bound to this document. dans stzHtml

Compter et mesurer

  • CountFileMatches matchings dans stzFolder
  • CountFolderMatches matchings dans stzFolder
  • NumberOfElements Count + accessors over the flat element index. dans stzHtml

Retirer

  • Delete DELETE OPERATIONS dans stzFileManager

Ajouter

  • AddFile MODIFICATION OPERATIONS dans stzZipFile
  • AddElement a leaf element with text. dans stzXmlBuilder

Découper et extraire

  • SplitByLines SPLIT OPERATIONS dans stzFileManager
  • ExtractTo EXTRACTION OPERATIONS dans stzZipFile

Ordonner et déplacer

  • MoveTo MOVE OPERATIONS dans stzFileManager

Convertir

  • ToHtml Serialise this node (tag, attrs, text then children) to HTML. dans stzHtmlBuildNode

Lire et écrire

  • Write WRITE METHODS (intent-specific) dans stzFileAppender
  • WriteSeperator @Misspelled dans stzFileAppender
  • Open open a container; every Add... until Close goes inside it. dans stzXmlBuilder

Les explications sont celles que la bibliothèque donne d'elle-même, en anglais, lues dans ses commentaires de documentation le 2026-10-01 04:14, from the library at commit 0e72e2e2c, by the library's own stzSelfDoc over 635 class sources.

La plateforme des artisans du logiciel à l'ère de l'IA. Née en Afrique. Utile au monde !

Chaque affirmation de ce site renvoie au fichier, au garde ou au rendu qui la prouve. Chaque bloc de code qui s'exécute a été exécuté le soir de la publication et sa sortie est à côté ; les autres le disent.

Les textes de ce site ont été rédigés avec un assistant d'IA, Claude, sous la direction de l'auteur ; le code, les exécutions et les chiffres viennent des dépôts. (Règle 99 de la constitution Zui : ce qui est fait par une machine le dit.)
