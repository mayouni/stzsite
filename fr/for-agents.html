Pour un agent d'IA

Un agent, ou la personne qui en déploie un : quoi lire, et ce que l'agent peut faire.

Par où commencer

la page Pour les agents: Agents d'IA.

Votre chemin

Chaque étape porte son état, avec les mots de la page Le patrimoine : construit, en construction, spécification, conçu, nommé.

Vous déclarez l'agent dans un fichier, vous lui donnez un monde sur lequel se tenir, et une règle que vous pouvez lire dit ce qu'il peut engager, ce qui pour un modèle est rien.

  1. Déclarer l'agent dans son propre fichier. construit · voir: Agents sûrs
  2. Le déployer comme un dossier : le dossier est le déploiement. construit · voir: Agents d'IA
  3. Le gouverner : un ensemble d'effets vide pour un modèle, une porte avant chaque acte. construit · voir: Agents That Cannot Hurt You
  4. Lui donner un fichier de connaissance comme monde. construit · voir: Wise coding
  5. Garantir qu'une personne peut toujours joindre une personne : le droit à un humain, ratifié et pas construit. conçu · voir: Agents sûrs
