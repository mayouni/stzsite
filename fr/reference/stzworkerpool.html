Dispatch
dispatch (admission + load isolation) ------------------------------ Dispatch fWork to the profile tagged pcTag. If the profile can admit (in-flight < budget), run it NOW (acquire -> call -> release) and return [ :admitted = 1, :result = <value>, :tag = pcTag ]. Else QUEUE it and return [ :admitted = 0, :queued = 1, :tag = pcTag ] -- Drain() runs queued work as slots free. A saturated profile queues WITHOUT touching any other profile's budget (load isolation).
Acquire
Reserve a slot WITHOUT running work (lets a caller model a long-running/in-flight job for isolation tests + the R8.3 fleet). Returns TRUE (slot taken) or FALSE (over budget).
