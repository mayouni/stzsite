SelfCost
What observation itself costs -- measured with the same clock it provides (the profiler profiles the profiler). Wall ms on the monotonic clock: sampling is straight-line sense-reading, so wall is the honest price (and Windows quantizes CPU too coarsely for per-sample readings anyway). Returns [ :samples, :totalMs, :perSampleMs ].
Tick
