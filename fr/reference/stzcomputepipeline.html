Run
running ------------------------------------------------------------ Thread pInput through every stage in order; each stage's output feeds the next. Returns the final output. Records a per-stage trace. A stage that RAISES is CONTAINED: the failure is traced, the facet slot is released (no leak), the pipeline HALTS and returns NULL, and Why()/ Failed() explain -- one bad stage never crashes the whole pipeline.
