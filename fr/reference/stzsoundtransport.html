Tick
being driven -------------------------------------------------------- One step. Cheap on purpose: it reads a counter and decides whether the sound has run out. Call it as often as you like.
RunToEnd
Tick until it stops, without a reactive loop. This DOES occupy the thread -- it is the honest version of PlayFor for a script that has nothing else to do, and it still reports the position while it runs.
RunFor

DriveWith
THE REACTIVE CONVERGENCE. The transport does not own a loop; it owns a STEP. Hand it a stzReactive and the loop that already exists calls the step, alongside every timer, stream and task that loop is already carrying -- which is the whole point of there being one loop.
