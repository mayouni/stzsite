the federated compute call ----------------------------------------- Discover a host offering pcFacet, gate the call (bond + governance capability lattice), and transport pcPath/pcBody to it via curl. Returns the remote response body; "" (with CallLastStatus < 0 and Why()) on refusal. The governed action is "use-<facet>".

SetMutualTls
Run the federation transport over WIRE mTLS: every FederatedCall now goes over a mutually-authenticated, encrypted mbedTLS channel -- this node PRESENTS pcCert/pcKey and VALIDATES the peer's server cert against pcCa (slices 2-3). Combined with governance (SLA) + request signing (per-request auth), this is the full node-to-node security stack: encrypted + mutually cert-authenticated + signed + governed.
