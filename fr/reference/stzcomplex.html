Conjugate
An ACTIVE verb mutates this number and returns nothing; the PASSIVE ...ed form returns the [re, im] DATA and leaves it alone; the Q twin returns a new stzComplex so calls chain. The first version of this class had Conjugate() and Negated() both returning new objects from plain names, which breaks the rule that a plain method returns data and only a Q form returns a Softanza object.
