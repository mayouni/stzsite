UseResponder
TEST / OFFLINE DOOR, named for what it is. The responder is a FAKE standing where the model stands: it receives (prompt, attempt) and returns the raw text a model would have returned. It exists so the refusal paths -- the ones that matter most and that no seeded cache can reach -- can be narrated without a GGUF. It spends budget like a real call, and Why() says "FAKE responder" on every answer it produces, so nothing it returns can be mistaken for a live one. (The name follows stzGraphRule.UseChecker(): same escape-hatch shape, same word.)

RunGoldens
Goldens hold STRUCTURES as readily as scalars now. Two things had to change for that, and both were real defects rather than gaps: Haro's own `=` answers 0 for two identical lists, so a structured golden could never have passed; and a failing structured case that reports only "expected / got" is unreadable, so the failure now carries the FIELD that moved.
