StopLoop
F5: the reactor is deliberately NOT destroyed here. The manager/http hold handle-sharing COPIES (Haro attribute assignment copies objects), so destroying from Stop() -- which timer callbacks may invoke MID-LOOP -- would leave those copies submitting on a freed loop (use-after-free). The idle loop thread is reclaimed at process exit; callers needing eager teardown may ReactorQ().Destroy() once no loop is running.aucune extension
