Référence · stzString

Replace()

Replace every occurrence of a substring with another.

aussi: replace substitute swap text find and replace change all rename substitute swap change find and replace put instead

Les formes de ce verbe

Replace · ReplaceQ · ReplaceW · Replaced · ReplaceCS · ReplaceWQ · ReplaceXT · ReplaceCSQ · ReplaceXTQ · ReplacedCS

Exemples de base (2)

Softanza
o1 = new stzString("R I N G")
o1.Replace(" ", "-")
# Replace() mutates the object
? o1.Content()
Sortie
R-I-N-G

? o1.Content()
o2 = new stzString("*** Ring programmin* language ***")
o2.ReplaceXT("*", :In = "programmin*", :With = "g")
# ReplaceXT(:In) fixes only the scoped star
? o2.Content()
Sortie
