ExtendToWithCharsRepeated()

Pad the string to total length n by cycling its own chars (mutating).

Exemples de base (1)

Softanza
o1 = new stzString("123")
o1.ExtendToWithCharsRepeated(8)
# '123' repeated up to width 8
? o1.Content()
Sortie
12312312

exécuté le 2026-10-02 04:23 dans la bibliothèque au commit 0e72e2e2c ; tiré de 138_extendtowithcharsrepeated.ring(s'ouvre dans un nouvel onglet)
