Référence · stzNumber

Same()

MATHEMATICAL equality, as opposed to Haro's `=` on the rendered strings. "1.50" and "1.5" are the same number; "0.1" and 0.1 are not the same BITS.

aussi: same number equal in value numerically equal

aussi écrite: IsSameAs

Exemples de base (2)

Softanza
oQ = StzNumberQ("1/3")
? oQ.Representation()
? oQ.IsExact()
oQ.Add("2/3")
? oQ.Content()
? oQ.Same(1)

? oPrice.Same("1.5")
# ...whether the other side is a string or a number

# ...and 1.6 is not

# 0 and -0 are the same number
? oZero.Same("-0")
# ...and so is 0.000
? oZero.Same("0.000")

# it compares against another stzNumber too
