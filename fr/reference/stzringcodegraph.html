RawCallEntries
The UNRESOLVED call targets, [ class, method, callee, line ] -- every identifier called in a method body, builtins included. CallEdges() keeps only calls to DEFINED methods (so it drops builtins like substr); a rule like engine-first needs to SEE the builtin calls, so it reads these. The line is the CALL SITE, and a `def substr(` is a definition (not harvested here), so this distinguishes a call from a definition -- which a text scan of "substr(" cannot.

DeadCode
DEAD CODE (honest scope): PRIVATE helpers (name starts "_") whose name is never referenced by any call in the scanned tree. Public methods are excluded -- they may be entry points called from outside this tree.
CyclicCalls
CYCLIC CALLS (honest scope): intra-class MUTUAL RECURSION -- method A and B in the same class each call the other (a 2-cycle). Self-recursion (A calls A) is legitimate and not reported. Name-based within one class.
