The perf-P6 closing of the loop: the load signal MEASURED instead of hand-fed. A stzPerfProfile's LoadRatio() is X/Xmax -- how close the observed workload is to its CPU ceiling -- read from the same engine instruments everything else trusts. Call it before each Supervise()/Cycle() pass (or from the same host tick).
Decide
the decision (PURE policy) ----------------------------------------- Given the current fleet metrics + reported load, return the actions to take: [ [ :restart, tag ], [ :scaleup, tag ], [ :scaledown, tag ] ]. Dead-worker restart takes precedence; then load-driven scaling within the [min, max] bounds. No side effects -- Supervise() applies these.
