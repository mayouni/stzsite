Une extension s'écrit à la fin du nom d'une méthode : c'est la même méthode, avec un mot de plus, jamais une autre méthode. Chaque méthode dit ci-dessous lesquelles existent : un nom en gras et coché existe pour elle, un nom barré n'existe pas. MinimalCutSets
THE MINIMAL CUT SETS of the top: the smallest sets of basic events that bring it about. Expanded down the tree -- an OR unions its inputs' sets, an AND crosses them -- then minimised: a set holding another is dropped, and duplicates fold. Each set is a list of basic ids in the order added; the sets come smallest first.aucune extension
CutSetProbability
THE EXACT PROBABILITY OF THE TOP, from the minimal cut sets by inclusion and exclusion over their unions -- the one number the gate arithmetic cannot give when a basic event is repeated. Every basic is still taken independent of every other. Refused above twelve cut sets, where the subsets outrun what a picture can mean.aucune extension
