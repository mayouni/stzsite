Magnitudes
EACH OF THESE IS ONE ENGINE CALL, not a transform this class then walks. The readings are what callers actually want -- raw complex bins are rarely the answer -- so they belong to the engine and every language over it, not to a loop written once per binding. |X_k| per bin: "how much of this frequency is present". Phase-blind, which is what you want when looking for a periodicity.
Phases
The phase angle of each bin, in radians.
PowerSpectrum
|X_k|^2 -- energy per bin, the quantity Parseval's theorem is about.
DominantBin
The engine excludes bin 0 and searches only the first half, and both matter: bin 0 holds the mean rather than a frequency and usually dominates, while a real signal's spectrum is conjugate-symmetric so the second half is a mirror. Getting either wrong names the wrong frequency; neither is a caller's problem.
DominantFrequency
The dominant frequency in cycles per sample-interval; multiply by a sample rate to get Hz.
