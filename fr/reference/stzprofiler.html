StartSampling
Sampling ------------------------------------------------- Start the engine sampler thread: every pnIntervalMs it photographs the active frame path. Constant cost, zero Haro involvement, honest at 1ms+ (the reactor's timeBeginPeriod(1) holds process-wide once any reactor exists; without one, Windows rounds the interval up to ~15.6ms -- fewer samples, same statistics).
